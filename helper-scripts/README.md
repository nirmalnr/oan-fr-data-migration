# Helper scripts

Scripts that support the migration without being part of it: exports, checks and comparisons. Each script has its own folder with a README that explains what it reads, how to run it and what it produces.

| Folder | What it does |
|---|---|
| [export-gen1-lists](export-gen1-lists/) | Exports Gen 1's code lists (its master data) from a Gen 1 database, read only and with no farmer data, for mapping to Gen 2 Master Data. |
